# Scoofyy PC — Контрольная работа №3

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## О проекте

Учебный интернет-магазин комплектующих для ПК.
Проект основан на первой контрольной работе и дорабатывается
для корректного отображения на телефонах, планшетах и компьютерах.

Адаптивная вёрстка выполняется без Bootstrap,
с использованием Flexbox, CSS Grid и медиазапросов.
